源图列出的参考包括李晓杰《东汉政区地理》、谭其骧《中国历史地图集》第三册及 Koba-chan 的地形图。本项目使用的是 Esiymbro 的开放授权数字地图，不代表获得了上述出版物全部内容的再分发授权，也不代表原作者认可本项目配准结果。

2026-11-08 的改动分两步：先提取 121 条郡界、14 条州界、3 条外缘线，以 13 个城市符号拟合仿射坐标、6 个独立检查点校对；再逐项识读全部 133 个郡级标签（包括编号对应的短名和 4 个属国标签），关联 14 州，记录别名、旧框架州属与沿革疑点。原图文字为字形路径，结合字形识读、图例编号和原典名称转写，未把 OCR 结果直接作为史料。

主图生成结果：**117 个闭合参考范围、14 个缺界郡、2 个侨置标签**。14 个缺界郡共处 3 片待考区域：河西的西海、敦煌、酒泉、张掖、西郡、武威、西平、张掖属国；幽州的乐浪、带方；益州的越巂、牂牁、益州郡、永昌。玄菟与北地为底稿明确标注的侨置，只有标签位置，没有独立郡域。保留缺界区内已有线段，不将同一面分配给多个郡。

`commandery-review.json` 保存每项名称、源图英文、源像素位置、州属、别名、文献及沿革说明；它是可继续校订的名录，**不是 133 个条目边界均已得到史学确证的声明**。《后汉书》郡国志用于东汉旧名及旧州属；《晋书》卷 14、15 和《三国志》相关卷次用于分置沿革。临川在这里指丹阳分置的短期郡，依据《朱然传》及裴注区分江西后来的临川；朱提与底稿名义 219 年有年代冲突；汉兴目前没有足以确认建置时段的原典依据。地图对这些问题明确标记，而非隐藏为确定事实。

几何整理采用共享线网：内部绘制接头距离不超过 12 原图像素、接海岸不超过 18 像素时连接至相邻线；共记录 251 次短接修补。较大缺口保留未定。67 个面积小于等于 8 原图平方像素的绘制碎面按最长共边并入相邻面，总面积约 18.2065 平方像素，不将其新编为郡。输出 374 条边界弧，其中包含未闭合的原图残线；闭合面共有 16,200 条不重复边。州域由所属郡域与待考面合成。

沿海闭合从原图内嵌地形背景（原作者注明 Koba-chan 地形图）提取海陆分色、7 像素闭运算和 1.5 像素轮廓简化，保存 1,022 个源像素顶点于 `source-coast.json`。这沿用的是**现代地形海岸**，没有复原古海岸。原底图图像不打包，仅分发派生线；Esiymbro / Koba-chan 的来源署名保留。以上派生地图文件均依 **CC BY-SA 4.0** 分享，详见许可文件。

重建线稿：`python3 scripts/build-history-reference.py`（标准库）。重建郡域：在有 Shapely 2.1.2 的 Python 环境运行 `python3 scripts/build-collated-atlas.py`；本工作区复用共享依赖：

```sh
env PYTHONPATH=/Users/wu/Code/agents-docs/_public-assets/python-gis/shapely python3 scripts/build-collated-atlas.py
npm run check:reference
npm run check:collated
```

网页和普通构建直接使用已提交数据，无需 Python。`collation-audit.json` 保存输入 SHA-256、修补记录、统计及未定名录；没有引入 CHGIS 或授权不明的数据。

**年代与位置限制**：原图名义年份为 219，部分州界采用 220 年后安排，不能当作八篇 184—280 年故事的同期区划。6 个检查点相对项目城池约位的差异中位 4.5 km、最大 26.1 km，不等于边界或测绘精度。原四篇的 8 个地点（赤壁、柴桑、汉津、乌林、广宗、濮阳、鄄城、白狼山）落在其文字关联参考郡域之外；姑臧、敦煌所属郡缺界。卡片显示原因提示，未移动原地点去迎合轮廓。具体差异的史学解决仍需更细的城址和分县文献。新旧对照不表示历史变化或误差区间。

## 旧版教学示意与地点旧属

`atlas-data.js` 与 `atlas-topology.js` 中 13 州部、52 个重点郡国的轮廓是本项目绘制的教学示意，**不是数字化历史地图、测绘边界或考证成果**。旧版曾供四篇共用，现仅供底稿对照与旧属说明，不逐年复原 184—208 年的省并、分置或军政控制；没有古代逐县边界数据。9 处尚未细分郡界的区域在数据中明确归属所在州，旧版主图曾用浅斜线与「郡界待补」说明，不表示没有行政归属。

隶属关系核对维基文库《后汉书》郡国志一至五，旧属出处为相应卷次：

- [卷 109 · 郡国一](https://zh.wikisource.org/wiki/後漢書/卷109)：司隶。
- [卷 110 · 郡国二](https://zh.wikisource.org/wiki/後漢書/卷110)：豫州、冀州。
- [卷 111 · 郡国三](https://zh.wikisource.org/wiki/後漢書/卷111)：兖州、徐州。
- [卷 112 · 郡国四](https://zh.wikisource.org/wiki/後漢書/卷112)：青州、荆州、扬州。
- [卷 113 · 郡国五](https://zh.wikisource.org/wiki/後漢書/卷113)：益、凉、并、幽、交趾部等。

旧框架中 65 个已收录地点关联州部、郡国及县治／地域地名；疏勒与龟兹单列西域地域说明，不强行套入州郡县。小沛按豫州沛国、平原按青州平原郡、广宗与下曲阳按冀州巨鹿郡、易京按冀州河间国易县附近关联；不因现代省名或战役叙述而改动层级。延津与乌巢根据酸枣条下注说明为渡口或地域约位，不列为独立县。交趾部、旧巴郡等名称沿革另附说明。

主图的底图参考关联改为平原属冀州、三辅属雍州，襄阳、夷陵、鱼复／永安、阆中、宕渠分别关联襄阳、宜都、固陵、巴西、宕渠；卡片另列旧东汉背景，不能理解为这些变化均在各篇故事年份生效。

文字来源支持层级与名称，不提供多边形坐标。轮廓为原创概略绘制，只表达地域关系，未进行逐年代边界考证。2026-11-07 修订为共享节点与面：相邻郡国共用边界，州界由下属郡国及明确归属的待补区域合成。修复陈国／陈留郡等重叠、济阴郡越州和接缝空洞，未引入新的外部历史 GIS 坐标。

`npm run check:atlas` 检查多边形自交、州郡间重叠、郡域越州、内部空洞、州内覆盖、共享边以及名称／地点锚点归属；构建会执行此检查。几何一致性通过不等同于真实历史疆界已被考证。开发检查使用 MIT 许可的 [polygon-clipping](https://github.com/mfogel/polygon-clipping) 做多边形交集、差集与并集运算；它是校验工具，不是历史数据来源，也不进入网页运行时。

荆州与今天的荆州市、汉九江郡与今天的九江市、吴县与吴郡等层级在详情中区分。夏口、樊口、汉津、赤壁等不一律标成县。赤壁与华容道以常见定位作示意；华容道未直接套用今天湖南华容县城。地点坐标不用于精确定位古城址、古河道、军营或行军道路。

本轮调查了 CHGIS、有关历史地图数据目录及江山时序等项目；因历史几何的用途许可、可再分发范围或来源精度不足，**未导入这些项目的历史 GIS 数据**，也未描摹商业历史地图的边界。

第三版取消长江中下游裁剪：现代省级数据保留全部 34 个源要素，县级保留 2391 个源要素，范围为经度 68—142、纬度 3—56。数字表示源数据条目，不是 2026 年行政单位统计。Natural Earth 陆地使用全球外环，河流与湖泊提取经度 60—150、纬度 -2—62；自然底图可在全国视野和各篇区域视野之间连续缩放。

地形来源：[Mapzen Terrain Tiles / AWS Open Data](https://registry.opendata.aws/terrain-tiles/)，读取日期 2026-11-07。按照[官方 Terrarium 格式说明](https://github.com/tilezen/joerd/blob/master/docs/formats.md)，将 PNG 高程编码解码为米，重投影到与矢量相同的经纬度栅格，通过高程分层设色和坡度光照生成晕渲。

- 全国：经度 68—142、纬度 16—56，z6 数据，3200×1977 WebP。
- 区域细图：经度 106—124、纬度 25—38，z8 数据，2400×1981 WebP。文件名保留 `terrain-chibi.webp`，现由各篇按同一缩放规则共用；范围之外使用全国晕渲。
- 脚本：`scripts/build-terrain.py`。上游瓦片复用 `~/Code/agents-docs/_public-assets/terrain-tiles/terrarium/` 缓存。
- 署名：Mapzen / Tilezen；global GMTED2010 and SRTM terrain data courtesy of the U.S. Geological Survey；global ETOPO1 terrain data U.S. National Oceanic and Atmospheric Administration。完整条款见[数据提供者署名说明](https://github.com/tilezen/joerd/blob/master/docs/attribution.md)。

晕渲使用现代高程，仅供认识山脉、盆地、平原和河谷；不是古代高程、古河道、精确军事地形或城防复原。色阶含视觉处理，不用来读取精确点高程。南海小图的东沙、西沙、中沙、南沙标签表示岛群约位，不绘制推测疆界。

新增历史城池与绿洲地名为地理索引，约位参考今地；城墙、城楼、船形、旗帜为原创 SVG 分类符号，不是城址平面或建筑复原。秣陵保留 208 年名称；[南京地方志资料](https://dfz.nanjing.gov.cn/gzdt/202403/t20240315_4186987.html)记载 211 年徙治秣陵、次年改名建业，故不提前使用后来的城名。全国地理覆盖不意味着已复原全部汉末政权与疆界；古政区现为各篇共用的东汉参考框架，详见前述精度说明。

## 赤壁之后至晋灭吴的故事篇章（2026-11-08）

新增第 5—8 篇覆盖 209—280 年，共63个事件、29位人物、60篇分节事迹和24个地点，分别为「荆益争雄」「三国鼎立与北伐」「三国后期与蜀汉覆亡」「晋吴对峙与统一」。原典链接随每个事件、每篇人物事迹提供，原典核对记录保留在任务材料 `late-periods/`。史籍故事是现代语言整理，包含明确的阅读解说；演义对照单独展示，不把小说对白、计谋场面或军事神迹当作已证事实。

- 荆益争雄：主要参照《三国志》武帝纪、先主传、吴主传、刘二牧传、张鲁与马超等传、关张马黄赵传、庞统法正传及周瑜鲁肃吕蒙传，分别梳理荆州、益州、关中与汉中的交叉进程。借荆州、关羽进兵及败亡等事件保留材料和系年的层次，不由小说章回确定逐日先后。
